# Tiny List Card: context for reviewers

This is a made-up test skill that formats small integer lists as plain-text cards. Its main rules are in `SKILL.input.md`. It is not meant to be installed or published as a real product.

Normal formatting keeps the input order and duplicate values. Explanation mode is separate and reads the reference only when requested. This README adds context but does not override the exact strings, validation order, or permissions in the main file.
